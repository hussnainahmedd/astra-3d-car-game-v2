# RoadShift v0.1.1

**RoadShift — Open World Delivery & Driving Simulator**

Drive a delivery van through a compact harbor district, accept contracts, collect
cargo, navigate to businesses, deliver it, earn rewards and maintain your van.
This native desktop prerelease uses Godot 4.3 stable and matching official export
templates. The game is single-player and offline.

## Changes

- RoadShift identity across the window, title screen, HUD, depot sign, icon,
  executable metadata, native packages, installer and CI artifacts.
- Rewritten player/developer README with the actual complete technology stack,
  controls, architecture, setup, building and release documentation.
- Explicit installer file selection to exclude obsolete binaries in reused
  export folders, and product-specific Windows package checksums.
- Existing vehicle/gameplay behavior and save-format/profile compatibility retained.

## Downloads

- **Windows installer:** `RoadShift-Setup-Windows-x64.exe` — normal per-user
  installation, Start Menu entry, optional desktop shortcut and uninstall support.
- **Windows portable:** extract `RoadShift-Windows-x64.zip`, then run
  `RoadShift.exe`; keep its adjacent `RoadShift.pck`.
- **Linux portable:** extract `RoadShift-Linux-x64.tar.gz`, then run
  `RoadShift.x86_64`; keep its PCK. Executable permissions are preserved.

Normal graphics/audio drivers and OpenGL 3.3 support are required. Players need
no separate engine or development tools. The archives include the playing guide,
game/engine notices and build provenance.

## Controls

**WASD / arrows** drive • **Space** handbrake • **Hold E** load/deliver •
**J** dispatch • **M** map • **G** workshop • **C** camera • **R** recover •
**H** headlights • **N** time of day • **Esc** pause • **F11** fullscreen •
**Right mouse + move** look around.

## Validation and scope

**PASSED:** editor/resource/script import, **79/79** logic checks and **64/64**
headless physics/input/UI checks, including a complete physically driven delivery,
payment, economy, save compatibility and settings. See the attached
`Windows-validation.txt`, `Linux-validation.txt` and
`SHA256SUMS.txt` for actual results, source provenance and artifact verification.
Headless Windows startup/installer checks are distinct from interactive graphics.

Interactive Windows rendering/audio, extended rendered release play and broad
hardware compatibility are **NOT TESTED**. VMware limits representative GPU and
performance validation. Current scope is one van and one compact district, with
simplified tires/damage and fixed-loop traffic; no multiplayer/controller menu.

Progress keeps the existing profile directory and save format v2. Uninstall
preserves user data. RoadShift code/resources use the repository's MIT license;
Godot/bundled-library notices are included in each package.
