# Astra 3D Car Game V2 — v0.1.0

Initial **test/prerelease-quality** native desktop build. Drive a physical delivery
van around the Harborline district, collect contracts, load cargo, navigate to
businesses, deliver it, earn rewards, upgrade the van, and continue your shift.
Built with official **Godot 4.3 stable** (`77dcf97d8`) and matching official release
templates; Windows resources use rcedit 2.0.0 and the real installer uses Inno Setup
**6.7.1**. The game is offline and includes its runtime and data.

## Features

- Force-based suspension/handling, three cameras, lights and free recovery.
- Six delivery locations, road-graph navigation, map, traffic and day/night.
- Standard/fragile/priority work, cargo condition, rewards, ranks and upgrades.
- Fuel/damage/service, local progress with backups, and audio/video/mouse settings.

## Install and play

**Windows x64:** run `Astra-3D-Car-Game-V2-Windows-x64-Setup.exe` for per-user
installation, Start Menu entry and uninstall support; or fully extract
`Astra-3D-Car-Game-V2-Windows-x64.zip` and double-click
`Astra-3D-Car-Game-V2.exe`. Keep the adjacent PCK with the portable executable.

**Linux x64:** extract `Astra-3D-Car-Game-V2-Linux-x64.tar.gz` and run
`Astra-3D-Car-Game-V2.x86_64` from the extracted folder. Executable permissions
are preserved; use `chmod +x` if your extractor removes them. Keep its PCK beside it.
Normal system graphics/audio drivers and OpenGL 3.3 support are required.
No source checkout, editor, development tools, localhost server or account is needed.

**First delivery:** Start your shift → **J**, accept Northline Works → stop and
**hold E** to load → follow the amber map route → stop in the destination ring →
**hold E** to deliver → receive payment → **J** for another contract.

## Controls

**WASD / arrows:** drive • **Space:** handbrake • **Hold E:** load/deliver •
**J:** dispatch • **M:** map • **G:** workshop • **C:** camera • **R:** recover •
**H:** headlights • **N:** time of day • **Esc:** pause • **F11:** fullscreen •
**Right mouse + move:** look around.

## Known limitations

One playable van and one compact stylized district; simplified tires/damage and
fixed-loop traffic. No controller/rebinding menu, multiplayer, modeled cockpit,
pedestrians or additional vehicles. High quality and first-use shaders can be
expensive on VMware; use **VM Low / 960 × 540** there.

Progress keeps the legacy `godot/app_userdata/Harborline Dispatch` folder, so the
product rename preserves existing saves. Uninstall leaves user progress intact.
See the included playing guide, `Windows-validation.txt`, `Linux-validation.txt`
and `SHA256SUMS.txt`. Game code/assets are MIT; engine/library notices are included.
