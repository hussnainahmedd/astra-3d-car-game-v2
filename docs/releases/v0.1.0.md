# v0.1.0 — archived initial desktop prerelease

This release predates the current **RoadShift** product naming. Its published
binaries, package filenames and release metadata remain intact for existing
downloads. Use the archived release page for those historical installation
instructions; current RoadShift instructions are in the README and playing guide.

## Delivered functionality

- A physical delivery van in the harbor district, collection/delivery contracts,
  road-graph navigation and rewards.
- Suspension/handling, three cameras, headlights, recovery and fixed-loop traffic.
- Cargo condition, standard/fragile/priority work, ranks and permanent upgrades.
- Fuel, damage, service, backed-up local progress and native menus/settings/audio.
- Official Godot 4.3 stable Linux/Windows desktop exports, portable packages and
  a real per-user Inno Setup installer.

## Recorded validation

- Editor import/script parsing; **79/79 logic** and **64/64 headless integration**.
- Physical driving through a complete loaded delivery, payment, progression,
  persistence/settings, traffic and service checks.
- Linux export/archive/ELF/PCK/permissions and independent startup, including a
  short native OpenGL launch on Ubuntu/VMware.
- Windows export/resources/ZIP, portable/installed headless startup, installation,
  Start Menu, reinstallation, uninstall and saved-data preservation.
- Engine **4.3.stable.official.77dcf97d8**, official matching templates,
  **rcedit 2.0.0** and **Inno Setup 6.7.1**.

Interactive Windows graphical gameplay, prolonged play and broad target-hardware
compatibility were not tested. These results are historical records and do not
replace the per-version validation attached to newer releases.
